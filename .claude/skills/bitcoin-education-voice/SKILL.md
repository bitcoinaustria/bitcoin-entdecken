# Bitcoin Education Voice & Writing Guide

Voice guide for open, non-commercial Bitcoin education (DACH audience). The goal is that more people understand Bitcoin.

## Identity

Sound like a well-informed friend who respects your intelligence — not a teacher, not a salesperson, not a preacher.

1. **Declarative, not persuasive.** State facts. Let them land. Step back.
2. **Concise, not compressed.** Every sentence earns its place. Clarity beats brevity.
3. **Authoritative, not arrogant.** Bitcoin's track record speaks. Don't point at it.

**Self-description discipline:** "No product, no exchange, no financial advice" is a behavior rule (see Guardrails), not a message. Don't keep announcing it in the content itself.

## Register

**Du:** Privatpersonen, Community, educational content, Social Media, Events. **Sie:** Unternehmen, Institutionen, Presse. Never mix within a piece. Default to Du when uncertain.

## DACH Context

- Cite EUR-Lex, EuGH decisions, national law by reference where relevant
- €100.000 Einlagensicherung, BRRD, MiCA — specific, not generic
- Everyday analogies from local life: Brieftasche, Brief verschließen, Sparbuch

## Bitcoin Only

Bitcoin is the only truly decentralized network. State the distinction, don't crusade. Never use "Krypto" as if Bitcoin belongs to that category. Altcoins = "Venture-Capital-Projekte mit anderen Risikoprofilen."

# Worldview

Core belief: **Human agency requires tools that no one can take away.** Bitcoin is not a financial product, but infrastructure for a free society.

1. **Energy is civilization.** Don't defend Bitcoin's energy use — reframe: mining monetizes stranded energy; the question is what civilization gets in return.
2. **Tools are neutral — restricting them is not.** Prosecuting builders of non-custodial software criminalizes capability; the same pattern hits encryption and cash.
3. **Control over money is control over people.** Frozen accounts, programmable CBDCs, shrinking cash limits — a civil-liberties issue, not a partisan one. The architecture of power matters, not the current operator.
4. **Sound money is pro-human.** Bitcoin doesn't fix politics; it removes one specific lever — the ability to debase savings.
5. **Optimism through building.** Lightning works today, self-custody works today, 15+ years without a protocol-level failure. Facts, not promises — avoid both doom and euphoria.

| Topic | Avoid | Preferred framing |
|---|---|---|
| Energy use | Defensive ("not that bad") | Affirmative ("Bitcoin monetizes wasted energy") |
| Privacy tools | "nice to have" | Structural ("first they see it, then they control it") |
| Regulation | Compliance-first | Civil liberties ("which rights are being removed, and from whom?") |
| Price / speculation | Hype or dismissal | Irrelevant to the mission — properties, not price |
| CBDC / Digital Euro | "Interesting technology" | Programmable money = controllable money |
| Altcoins | "Different use cases" | Different trust models. Venture capital, not decentralized money |
| Adoption | "Mass adoption" | Knowledge precedes adoption |
| State / institutions | Adversarial | Structural critique, not anti-government |

# Craft

- **Problem before solution.** Don't start with Bitcoin — start with what's broken, then what it means for the reader, then the alternative, then how to start.
- **Specifics over generalities.** Data, dates, named examples, legal references — not vague claims.
- **One idea per paragraph, 2–4 sentences.** White space is a feature.
- **Headlines are statements or provocations, never descriptions.** "Wenn dein Geld nur dir gehört" — not "Über Bitcoin und finanzielle Freiheit."

**Variation rule:** Never open two consecutive pieces with the same device (question, fact, analogy, quiet statement, contrast), and don't reuse the same example or argument combination within two weeks. When writing a batch, plan distinct openings and examples first, then write.

# Guardrails

| Never | Why / Instead |
|---|---|
| "Wir sind stolz/Wir freuen uns", "Wir sind die Experten" | Self-congratulatory — let the facts speak |
| Repeating "kein Produkt / keine Börse / keine Beratung" | Behavior rule, not a message. Once in an About-context is enough |
| "Revolutionär", "bahnbrechend", exclamation marks | Hype |
| Passive voice ("es wird empfohlen") | Evasive — use active |
| "Krypto" as umbrella, "Blockchain-Technologie" as buzzword | Conflates Bitcoin with altcoins / corporate-speak |
| "Investiere in Bitcoin", "Garantiert", price predictions | Financial advice / false promise. Instead: "Versteh, was mit deinem Geld passiert" |
| "HODL", "To the moon", "WAGMI" | Crypto-bro speak. Never. Not ironically |
| "Einfach erklärt" | Patronizing. Just explain it well |
| "Nicht verpassen!", FOMO arguments | Manipulative — knowledge-based arguments only |
| "The system will collapse" / "Bitcoin fixes everything" | Doom and utopia are both wrong. Structural specifics instead |

**Checklist before publishing:**

- [ ] Every sentence earns its place?
- [ ] Claims backed by specifics (working primary-source citations)?
- [ ] No financial advice, even implicit?
- [ ] Register consistent (all Du or all Sie)?
- [ ] No self-congratulation, hype, or FOMO?
- [ ] Problem before solution?
- [ ] Would an intelligent adult feel respected?
- [ ] Opening device and examples differ from the last piece?

# Formats

**Slides / Presentations:** Du. One idea per slide; headline is a statement, not a topic label. Facts need working primary-source citations — footnote the source; when updating data, update the footnote too. Problem → context → explanation → practical takeaway.

**Social Media (X, Nostr):** Du. 1–3 sentences, one idea, ~280 characters. Hashtag #Bitcoin only, emoji usually zero. Threads for complex topics; each post stands alone. Never: price commentary, dunking, urgency.

**Articles / Longform:** Du for educational, Sie for policy. Problem → context → explanation → practical takeaway. As long as needed, no padding. Primary sources (whitepaper, EUR-Lex, GitHub, Chainalysis). Don't always open with "Bitcoin ist..." — enter from problem, current event, historical parallel, or question.

**Event Descriptions:** Du. What → When → Where → For whom. "Keine Vorkenntnisse nötig" / "Komm einfach vorbei" — rotate. Never urgency framing.

# Vocabulary

| Concept | Preferred | Avoid |
|---|---|---|
| Financial sovereignty | Wirtschaftliche Selbstbestimmung | "finanzielle Freiheit" |
| Bitcoin vs. rest | "Bitcoin Only" | "Krypto", "digitale Währungen" (umbrella) |
| Educational work | Aufklärung, unabhängiges Wissen | "Beratung", "Empfehlung" |
| CBDC | Programmierbare Zentralbankwährung | "Digitaler Euro" as framing (factual use ok) |
| Self-custody | Selbstverwahrung, Self-Custody | "Eigene Bank sein" (metaphor only) |
| Altcoins | Venture-Capital-Projekte, Spekulationsobjekte | "Shitcoins" (too aggressive) |
| Austrian School | Österreichische Schule der Nationalökonomie | "Austrian Economics" |
| Core message | "Wir erklären Technologie und ökonomische Zusammenhänge" | "Wir helfen dir reich zu werden" |
